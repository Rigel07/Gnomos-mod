CARGA KAWAII 1.1.0 - COMO COMPILAR EL MOD CON GITHUB (sin instalar nada)

 1. Descomprime este zip en una carpeta.
 2. En GitHub crea un repositorio NUEVO (por ejemplo "carga-kawaii") y pulsa "uploading an existing file".
    NO lo mezcles con los repositorios de Corazon de Melon u Oruguitas: build.gradle y src se pisarian.
 3. Arrastra TODO el contenido de la carpeta, incluida la carpeta oculta ".github"
    (si no la ves, activa "mostrar archivos ocultos" en tu explorador). Commit changes.
 4. Pestana "Actions": espera a que el Build salga en verde (3-5 min) y descarga el artefacto "carga-kawaii".
 5. Dentro esta carga-kawaii-1.1.0.jar -> metelo en la carpeta mods de Minecraft Forge 1.20.1 (solo cliente).

SI EL BUILD SALE EN ROJO: abre el Build fallido en Actions, copia las lineas de "error:" y pasamelas.

PARA VERLO RAPIDO: abre el juego (arranque y menu principal) y entra a un mundo (Cargando terreno).
